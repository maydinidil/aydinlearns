## Decisions for the Claude Code planning session

1. **Engine and scheduler:** DuckDB-WASM (01, 04, 05, 07) and FSRS (02). Treat 02's SQLite parts and 08's SQLite / IndexedDB / SM-2 recommendation as superseded. Pin a DuckDB-WASM version (lambda syntax needs 1.3 or later; 01 cites an OPFS write bug in the npm "latest" build).
2. **Mistake log location:** the brief wants a file in the repo. OPFS and IndexedDB cannot do that, so the app needs a small local server (or the File System Access API).
3. **One grading spec:** merge 01 and 02 (column matching, rounding, partial credit, hidden datasets). Add DuckDB normalisation: `date_trunc` and `+ INTERVAL` return TIMESTAMP; DECIMAL vs DOUBLE; `1/0` gives inf and `0.0/0` gives NaN; NULLS LAST also applies to DESC; `CAST(8.7 AS INTEGER)` rounds to 9; DuckDB accepts a trailing comma, aliases in WHERE and `==`, so 02's syntax-error examples need replacing. Run every session with `SET TimeZone='UTC'`.
4. **One ID scheme:** SQL concepts appear as `SQL-*` (01), `C-JOIN-LEFT` style (02) and `CON-*` (04); GA4 topics as `GA4-*` (06) and `T-*` / names (07). Keep 01 and 06 as masters and map the others.
5. **Cases on company data:** port 04's cases onto 05's companies and re-date them to 2024 to 2025. 13 of 20 port directly. The other 7 need added tables: budget (CO-03); leads, opportunities, COGS and full S&M expense (CO-02); stock receipts, daily sessions and stores or move LFL to CO-01 (CO-04); rebates and a price-type flag (CO-01). Build 04's simplified tables as views so beginner cases stay simple.
6. **Logic fixes in 04:** CASE-PRICE-05 uses reserved words `both` and `only`; LFL total needs a "traded in both periods" rule (33.4% vs correct 0.2% on test data); RFM needs fixed frequency thresholds instead of NTILE; returns join fans out without a line key; markdown % uses a non-standard denominator; price index mixes net and shelf price; uplift and cannibalisation need a product-week spine; the funnel metric and CASE-MKT-03 disagree; drop the unverified NRF returns claim.
7. **Logic fixes in 05:** FIND-01-11 elasticity must be computed within SKU (gives -0.19 as written, -2.57 fixed); FIND-02-03 needs opening-balance MRR events; CO-01 orders need a ship-to country; FIND-01-09 needs chain-wide inventory; every finding needs a raw vs clean flag so quirks do not leak into beginner answers; write DDL, allowed values per category column and the reveal SQL.
8. **Difficulty ramp:** 04's cases are capstones and 01's 138 exercise patterns have no data or answer keys. Claude Code must generate the level 1 and 2 exercises (roughly 230 variants for the full path) on the company data.
9. **GA4 question bank:** shuffle answer positions, rewrite distractors as plausible GA4 features, fix Q-39 and Q-60 (thresholding), and grow the bank to about 200 questions after session 10.
10. **GA4 labs:** replace learner-captured reference answers with checks that need no stored answer (internal consistency, structural facts, first attempt re-checked a week later).
11. **Time plan:** 01 sizes SQL at about 128 hours; 06's plan assumes 20 h/week on GA4 only. Reconcile into one schedule (SQL daily, GA4 second).
12. **Thin JSON:** 04 case content, 07 bridge SQL and 03's top-12 ranking live only in the prose; the content pipeline must parse the markdown or these must be moved into JSON.

Test scripts from the review (DuckDB DDL, mock GA4 export, case runs) were kept only in the review sandbox, not in this repo.

### Additional decisions and fixes for the planning session

13. **Dataset line-up:** SaaS: KKBox transactions and members only (skip `user_logs`, about 28 GB saved). Pricing and promo: Breakfast at the Frat, Dominick's. Marketing spend: Robyn and Meridian (label "simulated") and Criteo cost/cpo (label "transformed"). TheLook: take and keep your own frozen snapshot.
14. **Prepare data outside the browser:** do all heavy loading (xlsx, BigQuery pull, `hf://`, multi-GB CSV, GA4 unnesting) in native DuckDB (Python or CLI) into flat Parquet, then load those files in the DuckDB-WASM app. WASM cannot use the excel or bigquery extensions and has a 4 GB memory limit.
15. **GA4 local route (R-GA4-01) works at $0.** Windows fixes: run `.venv\Scripts\python.exe` directly (or `Set-ExecutionPolicy -Scope Process Bypass` before `Activate.ps1`); install the DuckDB CLI (`winget install DuckDB.cli`); open a new terminal after installing gcloud; use 7-Zip for the KKBox `.7z` files.
